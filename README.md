## 🛠️ Troubleshooting Common Issues

**Issue: The download button does nothing.**  
Solution: Make sure you have copied the full URL correctly (including `https://`). Check your internet connection and try a different video URL.

**Issue: Windows SmartScreen warning appears.**  
Solution: Click "More info" then "Run anyway." This is standard for new open-source apps that have not been digitally signed yet.

**Issue: The app says "Unsupported URL."**  
Solution: The website you are trying to download from may not be supported. Try a different source.

**Issue: Downloaded video has no sound.**  
Solution: Ensure you selected "Video" (which includes audio) rather than "Video Only" if that option exists in the app. If audio is still missing, the source may have separate audio tracks – try downloading audio separately.
